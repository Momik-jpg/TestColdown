# schulNetz iCal-Link holen (mit Bild)

## Schritte
1. In schulNetz `Agenda` öffnen.
2. Links `Schüler/-innenpläne` auswählen.
3. Oben rechts auf `Exports` klicken.
4. `Diesen Plan im iCal Format abonnieren` wählen.
5. Im Dialog den Link **kopieren** (nicht öffnen).
6. Den Link in der App unter `Einstellungen -> Kalender verbinden` einfügen.

## Wichtig
- Nur `https://`-Links verwenden.
- Wenn der Link abläuft (z. B. HTTP 410), in schulNetz neu erzeugen.
- Keine echten Links in Chats oder Screenshots teilen.
